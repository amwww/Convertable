FAQ

Quick answers to common questions.

Is Convertable free?

Yes — you can distribute it however you like. If you publish it, consider linking back to the repo.

Why does video conversion sometimes slow down near the end?

Final container work (muxing / faststart) can take time on some files. Convertable keeps progress responsive and avoids large “stuck” jumps.

Can I run multiple conversions at once?

Yes. The queue supports multiple workers so you can process jobs in parallel and drag queued items between workers.

Can I choose an output folder?

Yes — set it in Settings. You can also reset to a temporary session folder.
